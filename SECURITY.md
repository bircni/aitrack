# Security & privacy

## What leaves your machine

| Action                                                                | Data sent                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `aitrack sync`, `aitrack recompute-costs` and opentrack's sync button | Claude Code and Codex usage is committed and pushed to **your** git remote (the repo you configured in `init`). Each machine file holds the machine name (`hostname`, also the file's name), `timezone`, `lastUpdated`, and per-day token counts, estimated costs, model names and `owner/repo` project names, which can name private repositories. It holds no credentials, local paths, git hosts or branches. `recompute-costs` also rewrites other machines' files when their costs change, keeping each file's encryption mode. See [Encrypting the synced files](docs/cli.md#encrypting-the-synced-files) for what encryption hides. |
| opentrack's sync button with **Sync settings** on                     | Off by default. The opentrack settings that mean the same on every machine (theme, how limits and reset times show, provider order and which are on, alert choices, compact view, tray provider and limit) and the time they last changed are committed to `opentrack/settings.json` in that repo and pushed, encrypted when `encryptData` is on. The file holds no credentials, tokens, paths, machine names or the shortcut. See [where data comes from](docs/opentrack.md#where-data-comes-from).                                                                                                          |
| opentrack's background pull and `aitrack doctor`                      | opentrack runs `git pull` on that repo every 30 minutes unless turned off in Settings. `aitrack doctor` runs `git push --dry-run` against it. Neither sends usage data.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| opentrack provider limits                                             | Reads the logins Claude Code and Codex already saved and sends each token only to its own provider's usage endpoint: `https://api.anthropic.com/api/oauth/usage` and `https://chatgpt.com/backend-api/wham/usage`. A provider turned off in opentrack Settings is neither read nor contacted, and the sync button leaves its logs unread, so its newer usage is not pushed; `aitrack sync` still syncs every provider. See [where data comes from](docs/opentrack.md#where-data-comes-from).                                                                                                                                               |
| Pricing refresh                                                       | `aitrack sync`, `aitrack doctor`, `aitrack recompute-costs` and opentrack's sync button download the rate pack from `https://raw.githubusercontent.com/bircni/aitrack/pricing/` (or `AITRACK_PRICING_URL`) into `~/.config/aitrack/pricing/`, at most once a day (30 minutes after a failure). No usage data or credentials are sent. `AITRACK_NO_PRICING_REFRESH=1` turns it off and keeps the cached or bundled rates.                                                                                                                                                                                                                   |
| opentrack update check and `aitrack install-opentrack`                | Fetches `latest.json` and, when installing, the installer from this project's latest GitHub release. opentrack checks shortly after launch and every six hours; development builds never check.                                                                                                                                                                                                                                                                                                                                                                                                                                            |

## What stays local

- Config (`~/.config/aitrack/config.json`) stays on disk locally. It can contain the git remote URL, machine ID, additional Claude/Codex source paths, and a monthly budget; none of the config file itself is copied into the data repo.
- A `repoUrl` holding a token is masked in `init`, `doctor`, `config list` and `config set` output. `config get` and `config list --json` print it as stored.
- Working directories of work without a git remote stay in the local parse cache and are never synced.

## Recommendations

- Use a **private** git repository for your usage data.
- Turn on [`encryptData`](docs/cli.md#encrypting-the-synced-files) if whoever hosts that repository should not read your usage or project names.
- Do not commit your data repo URL or machine JSON files into this project’s source tree.

## Desktop app

opentrack's dashboard runs under a content security policy that allows only the app's own scripts and styles, no inline ones, and connections only to the app's IPC. Network requests come from its background service and Rust shell, not the dashboard.

## Reporting vulnerabilities

If you find a security issue in aitrack itself, please
[report it privately through GitHub Security Advisories](https://github.com/bircni/aitrack/security/advisories/new).
Do not disclose sensitive details in a public issue.
